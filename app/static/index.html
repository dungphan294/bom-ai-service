BOM AI Service

checking…

A small tool for engineering paperwork. It reads a customer email or an Excel parts list (bill of materials, BOM), does the maths in Python and lets an AI write the summary text. Every result is a draft for a person to check.

1Paste a customer email Get the part, material, quantity, size, supplier and deadline as a clear list.
2Upload an Excel BOM Get totals, weight per material and a list of rows with missing data.
3Download a Word report The same analysis as a .docx file you can edit and send.
